# Cross-Project Feedback

Use this when Grow discovers a reusable Studio Pattern improvement.

## Standing Rule

When Grow reveals a reusable lesson about handoffs, review boundaries, human-mediated relay, machine roles, or agent collaboration, preserve the lesson locally first and then route it back to the canonical Studio Pattern.

Canonical target:

- Repository: `https://github.com/ArneGleason/the-studio-pattern`
- Local reference checkout: `/Users/arnegleason/code/github.com/arnegleason/the-studio-pattern`

If direct edits to the canonical repo are available in the current environment, update the relevant docs or templates there. If they are not available, create a feedback note under `.agent/cross-project-feedback/` in this repo so Arne can route it manually.

Record the local evidence first:

- What happened?
- Which file or workflow helped or failed?
- What small change would improve future sessions?
- Is the lesson Grow-specific or reusable?

Then route the feedback to the canonical `the-studio-pattern` repository through the human owner.

Prefer improving canonical head docs or templates when the lesson changes how future projects should work, not just how Grow works.
