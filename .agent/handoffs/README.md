# Handoffs

Store timestamped handoff notes here when work moves to another agent, reviewer, machine, or future session.

Each handoff should include:

- From: the agent/tool and machine/environment that authored the handoff.
- To: the intended recipient agent/tool and machine/environment.
- Relay: the human owner when the handoff is manually copied, pasted, annotated, or withheld.
- Task summary.
- Current branch and commit.
- What changed.
- Validation run.
- Known risks or follow-up questions.
- Suggested first reads for the next participant.

The human-mediated relay is intentional. Even when the text is written by an agent for another agent, Arne may edit, annotate, omit, or redirect the handoff before the recipient sees it.
